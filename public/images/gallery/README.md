Drop real trip photos here (jpg, jpeg, png, or webp).

Each file appears automatically on the /gallery page under a new
"Trips" filter — no code changes needed. The caption is generated from
the filename, so name files descriptively with hyphens or underscores,
e.g.:

  sunrise-safari-march-2026.jpg  ->  "Sunrise Safari March 2026"
  family-trip-ella.jpg           ->  "Family Trip Ella"

This file itself is just documentation and is ignored by the gallery
(only .jpg/.jpeg/.png/.webp files are picked up).
